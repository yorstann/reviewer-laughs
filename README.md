# The Joke the Reviewer Laughs At

A tiny Node program that assembles a single one-line joke about working beside AI coding agents — a setup joined to its punchline, with a built-in character-count self-check — and writes it to `entry.txt` in the output directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`). The finished joke runs to exactly 96 characters. Standard library only; run it with `node main.ts` on Node 22.
